Adds an icon to the system tray and allows minimizing anki to the tray when the icon is pressed or when the main window X button is pressed. Configuration
To start Anki minimized in the tray go to Tools > Add-ons > Minimize to tray > Config and set the variable hide_on_startup to true To enable debug mode (for troubleshooting), set the variable debug to true in the same config menu. Debug messages will be printed to the console. Flatpak
The Flatpak version of Anki has no access to the system tray, so the add-on works with some limits: the tray icon only appears while Anki is hidden, and clicking it can only open Anki. To get the full tray icon, run this command in a terminal and restart Anki: flatpak override --user --talk-name=org.kde.StatusNotifierWatcher net.ankiweb.Anki Changelog
